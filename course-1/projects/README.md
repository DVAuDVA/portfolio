## Итоговый проект (Отчёт):

### 1) Реализован обязательный функционал Telegram-бота:
- Бот успешнотзапускается через открытие тоннеля.
- Команды /start и /help работают корректно.
- Команды /stats, /clear, /summarize и /undo работают не вызывая ошибок работы, однако не удаётся подтвердить выполняют ли комманды взаимодействие с историей чата.

### 2) Реализован дополнительный функционал Telegram-бота:
- Реализована дополнительная команда /joke.
- Функционал комманды работает корректно, LLM от OpenAI успешно отправляет в чат максимально не смешные шутки.

## Запуск программы.
1. Перед запуском приложения необходимо поднять тоннель через консоль, введите в окно консоли команду:
- lt --port 5000 --subdomain mytelegrambot.

2. Ждём когда консоль ответит, затем необходимо создать новое окно консоли и ввести следущую комманду, предварительно вставив токен и заменив ссылку https://mytelegrambot.loca.lt на полученную в прошлом окне.
- curl -X POST "https://api.telegram.org/botВАШ_ТОКЕН/setWebhook?url=https://mytelegrambot.loca.lt/api/Update&quot;

3. Теперь можно запустить сам бот и начать взаимодействие с ним.
