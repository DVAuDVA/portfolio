## Итоговый проект (Задача):

### Цель:

Разработать Telegram-бота на ASP.NET Core, который принимает сообщения пользователя через webhook, сохраняет историю диалога и выбранную модель, отправляет контекст в OpenRouter и возвращает пользователю ответ.
##### Для выполнения цели необходимо выполнить практики занятий №26-№38.



###   Также, можно самостоятельно реализовать одну опциональную функцию для Telegram-бота:

- Создать команду /system <text> – добавление системного сообщения в историю (role=system), влияющего на стиль ответов.
- Создать команду /history N – просмотр последних N сообщений в чате.
- Создать команду /joke, /quote случайная цитата и шутка от LLM.
- Перенести хранение истории и модели из памяти в json.
- Предложить свою идею (должна быть соизмерима с предложенными вариантами по реализации).
