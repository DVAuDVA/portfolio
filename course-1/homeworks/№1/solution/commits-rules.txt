Данный блок относится к правилам оформления комманды
git commit -m "[данные]", если вы искали список комманд - см. приложенный файл "commands.txt".

  Правила оформления "[данных]":
1) Сохраняя ковычки в комманде, одним "словом" записываем один из четырёх типов коммита:
feat: - новый функционал.
fix: - исправление ошибок.
docs: - изменения в документации
refactor: - изменения в коде невидимые пользователю.
2) Ставим пробел и пишем суть коммита (нужно писать на латинице, т.к. консоль использует "Unicode", который не поддерживает другие языки).
  Пример полной комманды:
git commit -m "feat: added new summoner weapon"
