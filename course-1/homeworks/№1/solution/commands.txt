Основные комманды "Git"-а:
cd .. - переносит пользователя на уровень выше, относительно папки в которой пользователь находится сейчас.
cd [название папки] - переносит пользователя в выбранную папку, выбранная папка должна находится в текущей.
git add - добавляет файл репозитория в список отслеживаемых программой.
git init - инициализирует скрытый репозиторий, предназначенный для хранения истории изменения файлов.
git commit -m "[данные]" - создаёт комментарий к нововведениям в файле (правила оформления "[данных]" описаны в приложенном файле - commits-rules.txt).
